Dr. Exam

AI-powered proctoring for Windows 11.
Face detection, gaze tracking, screen recording, and real-time analysis - all in one desktop app.

Windows 11
Capabilities

Everything you need for exam proctoring.

Face Detection

Real-time face detection using YOLOv8. Tracks multiple faces, verifies presence, and logs absences automatically during exams.

Gaze Tracking

Advanced gaze estimation powered by MediaPipe. Detects when a candidate looks away from the screen and flags suspicious behavior.

Screen Recording

Automated screen capture with timestamped logs. Every second of the exam is recorded for offline review and audit trails.

Proctor Dashboard

Real-time monitoring dashboard with live alerts. View all candidates at a glance with color-coded risk indicators.

Offline Mode

Works without internet. All proctoring data is stored locally and syncs automatically when the connection is restored.

Privacy First

All processing happens on-device. No cloud uploads, no video streaming. Your data stays on your machine.
