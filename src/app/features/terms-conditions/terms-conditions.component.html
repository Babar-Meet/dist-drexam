3. Description of Software

Dr.Exam is a Windows desktop application built with Python that provides AI-powered remote exam proctoring. Features include face detection and landmark tracking (via MediaPipe), head pose estimation, gaze tracking, object detection for prohibited items (via YOLOv8), screen capture and scene-change detection (via mss), browser URL monitoring, foreground window tracking, and CSV-based evidence logging with snapshot capture. All processing runs locally on your device with no cloud dependencies. The Software is provided for educational and examination supervision purposes only.
