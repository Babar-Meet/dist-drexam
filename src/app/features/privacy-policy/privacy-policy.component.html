Privacy Policy

Effective: July 25, 2026

1. Our Belief

Dr.Exam is designed with a local-first, privacy-respecting philosophy. All processing happens on your device. No tracking, no profiling, no data mining, and no cloud uploads. Your data stays yours.

2. What We Access & Store

Dr.Exam accesses the following system resources strictly for real-time proctoring. Everything stays local:

  • Camera Feed (On-Device): Accessed for face detection via MediaPipe Face Landmarker, head pose estimation, and gaze tracking. Video frames are processed in memory and never transmitted. Snapshot images may be saved locally when configurable thresholds are breached.
  • Screen Capture (On-Device): Periodic screenshots are captured via the mss library for scene-change detection using perceptual hashing (pHash). These captures are compared locally and only snapshots of significant changes are stored to disk.
  • Foreground Window & Browser URL: The active window title and foreground process name are polled to determine focus state. When a browser is focused, the active URL may be extracted via UIA or DevTools Protocol for domain/path allow-list checking. No browsing history is collected.
  • Proctoring Evidence Logs: CSV files containing timestamps, violation types, focus state transitions, and snapshot references are saved locally in the evidence/ directory. These logs are never transmitted automatically.
  • Object Detection (On-Device): YOLOv8 runs locally to detect prohibited items (phones, laptops) in the camera frame. No images are sent to any external service.

3. No Third-Party Services

Dr.Exam does not integrate any third-party analytics, telemetry, crash reporting, advertising, or tracking services. The application is fully self-contained with no external network calls for its core functionality.

4. Data Storage

  • Local Only: All evidence logs, snapshots, and configuration are written to the local filesystem under the evidence/ and exports/ directories relative to the application data folder. You have full control over these files.
  • No Cloud Sync: Dr.Exam does not offer cloud storage, cloud sync, or remote backup. No data leaves your machine unless you manually copy it.
  • Uninstall: Deleting the application and its data directory removes all stored information from your device.

5. Data Security

Because all sensitive processing (face data, screen content, URL information) happens on-device, the attack surface is minimized. The application runs with the permissions granted by the user. No server-side infrastructure exists that could be compromised to expose your data.

6. Your Control

  • Camera & Screen Permissions: You can revoke camera and screen access at any time through Windows Privacy Settings.
  • Local Data: Navigate to the application data folder and delete the evidence/ directory to remove all logs and snapshots immediately.
  • Manual Export: Evidence logs can be exported manually for institutional review. You decide what leaves your device and when.
  • Configuration: All proctoring thresholds and allow-lists are configurable via local files. No configuration data is transmitted.

7. Policy Changes

This policy may be updated at any time. Changes take effect when posted. Continued use of the Software after changes constitutes acceptance of the updated policy.

8. Contact

This software is distributed privately. For any privacy-related inquiries, contact the person or organization who provided you access to this application.
